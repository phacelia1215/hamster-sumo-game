# ハムスター大相撲！ころりん場所

ハムスターを育てて横綱をめざす、ブラウザで遊べる3D相撲育成ゲームです。

- **ハムスター選択** — ゴールデン / ジャンガリアン / キンクマ / ロボロフスキー / パールホワイトの5種。四股名もつけられます。
- **3Dモデル** — Three.js のプリミティブだけで組んだ、まわし姿のハムスター。十両で大銀杏、横綱で綱がつきます。
- **育成** — 四股・てっぽう・ぶつかり稽古・回し車ダッシュ・ひまわりの種・おひるね。1日3回、元気と相談しながら稽古します。稽古ごとに専用のアニメーションと演出つき。
- **着せ替え** — 取組の懸賞でもらえるひまわりの種で、毛色・まわし・化粧まわしを購入。カツラは番付ごとに解禁（ちょんまげ〜綱大銀杏）。
- **取組（自動）** — 力・技・体・速・心の5能力で立合いから決まり手までを自動進行。入場・塩まき・四股・仕切りから立合い、決まり手、行司の軍配まで演出します。番狂わせでは座布団が舞います。
- **番付** — 1場所7日。30力士の成績で番付が毎場所入れ替わり、幕下から横綱まで昇進・陥落します。

## 遊び方

`index.html` をブラウザで開くだけです（Three.js は CDN から読み込みます）。セーブはブラウザの localStorage に自動保存されます。
